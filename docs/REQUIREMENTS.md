# CodeShift HR – Project Requirements

## 1. Functional Requirements

**FR1 – Labour Law Search**

The application must allow HR executives to search for labour laws using keywords.

**FR2 – Old and New Law Mapping**

The application must display the mapping between old labour laws and new labour code sections.

**FR3 – Labour Code Information**

The application must provide information about the four new labour codes and their sections.

**FR4 – Salary Structure Checker**

The application must allow HR executives to check salary structures and understand possible PF and gratuity impacts.

**FR5 – Document Management**

The application must allow users to view and retrieve stored labour law documents.

## 2. Non-Functional Requirements

**NFR1 – Performance**

The application should return normal search results within 2 seconds.

**NFR2 – Availability**

The application should maintain at least 99% availability during the target operating period.

**NFR3 – Security**

The application must protect confidential employee salary information and must not expose private data.

**NFR4 – Reliability**

The application should process 100 consecutive API requests without unexpected failure during testing.

**NFR5 – Scalability**

The application should support at least 100 simultaneous users during performance testing.
